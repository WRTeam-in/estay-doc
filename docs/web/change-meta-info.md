# How to Change Meta Info

Meta information controls how your site appears in search engines and social media previews.

---

## Meta Information

### Step 1 — Open the Environment File

```
.env
```

### Step 2 — Update Meta Details

Find and update the following keys:

```env
NEXT_PUBLIC_META_TITLE=eStay — Find Your Perfect Stay
NEXT_PUBLIC_META_DESCRIPTION=Book hotels, homes, and rentals at the best prices.
NEXT_PUBLIC_META_KEYWORDS=hotel booking, stay, rental, accommodation
```

![Meta details configuration](/images/web/meta_details.png)

:::info
Keep `NEXT_PUBLIC_META_TITLE` under 60 characters and `NEXT_PUBLIC_META_DESCRIPTION` under 160 characters for best SEO results.
:::
