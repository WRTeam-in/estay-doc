# Frequently Asked Questions

<details>
<summary>What platforms does eStay support?</summary>

eStay supports Android, iOS, and Web platforms.

</details>

<details>
<summary>What backend technology does eStay use?</summary>

eStay uses Laravel (PHP) for the backend API and admin panel.

</details>

<details>
<summary>Can I white-label eStay?</summary>

Yes. You can customize the app name, logo, colors, and package name as described in the App Setup section.

</details>

<details>
<summary>How do I update to the latest version?</summary>

See the [Update System](./admin/update-system.md) section in the Admin Panel docs.

</details>
