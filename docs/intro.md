# Welcome to eStay Documentation

eStay is a complete property booking and rental platform that includes an Admin Panel, Mobile App, and Web Application.

## What's Included

- **Admin Panel** — Manage properties, bookings, users, payments, and more
- **Mobile App** — Flutter-based app for iOS and Android
- **Web Application** — Next.js-based web frontend

## Getting Started

Choose a section from the sidebar to begin:

- [Admin Panel Setup](./admin/installation.md)
- [Mobile App Setup](/docs/app/prerequisites)
- [Web App Setup](/docs/web/setup)

## Requirements

- PHP 8.3+
- MySQL 5.7+ / MariaDB 10.3+
- Node.js 18+
- Flutter 3.x
