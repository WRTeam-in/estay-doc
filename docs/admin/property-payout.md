# Property Payout

A booking-by-booking ledger of what each partner earns after commission, and whether it's already been credited to their wallet.

:::info Multi-mode only, and country-scoped
This page exists only in [Multi Mode](./overview.md#single-mode-vs-multi-mode), scoped to the country selected in the topbar.
:::

---

## The List

Shows Confirmed, Checked-in, and Completed bookings.

| Column | Description |
|---|---|
| **Booking ID** | Searchable. |
| **Property** | Property name, with the owning partner's name underneath. |
| **Check-in** | Booking's check-in date. |
| **Booking Amount** | The base booking amount, before commission. |
| **Commission** | The platform's cut, per [Commission Management](./commission-management.md). |
| **Partner Credit** | What the partner actually earns for this booking (booking amount minus commission). |
| **Credited** | A checkmark if the amount has already been credited to the partner's wallet, a clock icon if it's still pending. |
| **Credited At** | The date it was credited, if it has been. |

Filter by **Payout Status** (Credited / Pending) or **Booking Status**.

:::info When crediting happens
Crediting to the partner's wallet happens automatically at **guest check-in** — you don't manually credit from this page. This is a read-only ledger for reconciliation and support.
:::
