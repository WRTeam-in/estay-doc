# Review Removal Requests

The queue of reviews a partner has asked to have taken down (see [partner-side removal requests](/docs/partner/reviews#requesting-a-removal)) — you decide whether it comes down.

:::info Multi-mode only
This page exists only when the platform is running in [Multi Mode](./overview.md#single-mode-vs-multi-mode).
:::

---

## The List

Rating and comment, customer and review date, and the **partner's stated reason** for requesting removal. Click a row to see the full review.

![Review Removal Requests](/images/panel/reviewremovalrequestsstep1.png)

**Approve Removal** takes the review down (it then shows up in [Removed Reviews](./removed-reviews.md)). **Reject Request** leaves it published.
