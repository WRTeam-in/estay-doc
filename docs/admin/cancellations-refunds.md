# Cancellations & Refunds

A read-only oversight list of every **cancelled booking** across partner properties in your selected country, and where its refund stands.

:::info Multi-mode only
This page exists only when the platform is running in [Multi Mode](./overview.md#single-mode-vs-multi-mode).
:::

:::info Not the same as Manual Refunds
This page is for **visibility** — seeing every cancellation and its refund outcome. [Manual Refunds](./manual-refunds.md) is where you **act** on a specific case: when a customer's automatic refund fails, they submit their bank details there and your team processes the transfer manually. A booking showing **Refund Failed** here is a candidate for that — but the customer has to submit the manual refund request themselves; it doesn't happen automatically.
:::

---

## The List

| Column | Description |
|---|---|
| **Booking Info** | Booking number (links to the full booking) and creation date/time. |
| **Customer Info** | Guest name and email. |
| **Property Info** | Property name, type, and city. |
| **Room Details** | Room type and room number. |
| **Booking Dates** | Check-in → check-out, with nights/days. |
| **Payment** | Original payment status and method. |
| **Refunded Amount** | Total refunded so far across all payments on this booking. |
| **Status** | **Refunded**, **Refund Processing**, **Refund Pending**, **Refund Failed**, or plain **Cancelled** (no refund applicable) — with the cancellation date underneath. |

**View** opens the full booking. Export is available.

---

## Where to Go Next

- **A refund shows Refund Failed?** → the customer can submit a bank-transfer request in [Manual Refunds](./manual-refunds.md).
- **Guests who paid on arrival instead** → [Pay At Property Bookings](./pay-at-property.md).
