# Pay At Property Bookings

A tracking list of bookings where the guest chose to pay on arrival instead of online, across every partner property in your selected country. It's read-only — a monitoring view, not a place to take action on the booking.

:::info Multi-mode only
This page exists only when the platform is running in [Multi Mode](./overview.md#single-mode-vs-multi-mode).
:::

---

## The List

Shows Confirmed, Checked-in, or Completed bookings paid by **Pay At Property** that aren't yet marked fully paid.

| Column | Description |
|---|---|
| **Booking Info** | Booking number (links to the full booking) and creation date/time. |
| **Customer Info** | Guest name and email. |
| **Property Info** | Property name, type, and city. |
| **Room Details** | Room type and room number. |
| **Booking Dates** | Check-in → check-out, with nights/days. |
| **Financial Summary** | Total booking amount. |
| **Payment** | Payment status badge and method. |
| **Status** | The booking's status. |

**View** opens the full booking; **Download** gets the invoice. Export is available.

:::info Where the "paid" status comes from
This page just tracks these bookings — it doesn't have a "mark as paid" action. Payment status updates when the property actually collects payment (recorded through the normal booking/check-in flow), the same as any other booking.
:::
