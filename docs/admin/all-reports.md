# All Reports

**All Reports** is a searchable directory of every report available in Multi Mode, organized into five groups. Pick a tab (or search across all of them), then open a report card to see its dedicated page — each with its own filters, summary stats, detailed table, and export.

:::info Multi-mode only
This page exists only when the platform is running in [Multi Mode](./overview.md#single-mode-vs-multi-mode).
:::

![All Reports Hub](/images/panel/allreportsstep1.png)

---

## Report Groups

### Booking & Customers

| Report | What it shows |
|---|---|
| **Booking Report** | Details of all bookings created on the platform. |
| **Cancellation Report** | List of canceled bookings with refund details. |
| **Customer Report** | Details of all customers on the platform. |

### Partner & Property

| Report | What it shows |
|---|---|
| **Partner Report** | Partner accounts and performance overview. |
| **Partner Payout Report** | All partner payouts and settlements. |
| **Partner Wallet Report** | Partner wallet transactions. |
| **Property Report** | Summary of all listed properties. |
| **Property Verification Report** | Property verification activity. |

### Financial

| Report | What it shows |
|---|---|
| **Revenue Report** | Total revenue and deductions. |
| **Commission Report** | Commissions earned, by partner or property. |
| **Tax Report** | Summary of applied taxes. |
| **Refund Report** | All customer refunds and approvals. |
| **Transaction Report** | End-to-end financial activity log. |
| **Finance Summary Report** | Consolidated monthly finance overview. |

### Feedback & Rating

| Report | What it shows |
|---|---|
| **Feedback & Rating Report** | Guest feedback and ratings summary. |

### System Activity

| Report | What it shows |
|---|---|
| **Login Report** | All login attempts across roles. |
| **Notification Report** | Platform notifications sent. |

---

## Finding a Report

Use the **search box** to filter report cards by name or description — it searches within whichever tab is active, or across everything on the **All Reports** tab.
