# General Settings

Configure your eStay platform's core identity, branding, and regional preferences from one place.

**Navigate to:** Sidebar → **Settings** → **General Settings**

![General Settings](/images/panel/general-settings.png)

---

## System Identity

| Field | Description |
|---|---|
| **System Name / Company Title** | The name of your business or platform. Displayed in the admin panel header and emails. |
| **System Email** | The primary contact email address for the platform. |
| **System Phone** | The primary contact phone number. |
| **System Address** | Physical address of your company or property. |

---

## Branding

| Field | Description |
|---|---|
| **Favicon** | Small icon shown in the browser tab. Recommended size: **32×32 px** (`.ico`, `.png`). |
| **Logo (Light)** | Logo displayed on light/white backgrounds. |
| **Logo (Dark)** | Logo displayed on dark backgrounds or dark mode. |

:::info
Upload logos in PNG format with a transparent background for best results across both light and dark themes.
:::

---

## Currency

| Field | Description |
|---|---|
| **Currency Name** | Full name of the currency (e.g., `US Dollar`). |
| **Currency Symbol** | Symbol shown alongside prices (e.g., `$`). |
| **Currency Code** | ISO 4217 currency code (e.g., `USD`). |

:::warning
Changing the currency after bookings have been made will not retroactively update existing booking amounts. Only future transactions will reflect the new currency.
:::

---

## Regional Settings

| Field | Description |
|---|---|
| **Timezone** | Server timezone used for booking dates and notifications. |
| **Date Format** | How dates are displayed across the platform (e.g., `DD/MM/YYYY`, `MM-DD-YYYY`). |
| **Default Language** | The default language for the customer-facing interface. |

---

## Other Settings

| Field | Description |
|---|---|
| **Copyright Text** | Text shown in the footer of the website (e.g., `© 2025 eStay. All rights reserved.`). |
| **Maintenance Mode** | Toggle to put the customer-facing site into maintenance mode. The admin panel remains accessible. |

:::warning
Enabling **Maintenance Mode** will make the website inaccessible to all visitors. Use this only during updates or server maintenance.
:::

---

## Saving Changes

After updating any field, click the **Save** button at the bottom of the form. Changes take effect immediately.
