# Other Pages

This section covers the management of supplementary content pages in the eStay admin panel: Banners, FAQs, Blogs, and How It Works.

---

## Banners

Banners are promotional images displayed on the home screen of the app and web frontend.

Navigate to the **Banners** section in the admin sidebar.

![Banners List](/images/panel/banners-list.png)

### Managing Banners

| Field | Description |
|---|---|
| Banner Image | Upload the banner image (recommended: 1200×400px) |
| Link / URL | Optional URL to open when the banner is tapped |
| Display Order | Controls the order banners appear in the carousel |
| Status | Enable or disable the banner |

### Steps to add a banner

1. Go to **Banners** in the sidebar.
2. Click **Add Banner**.
3. Upload a banner image.
4. Set an optional link URL.
5. Set the display order.
6. Toggle status to **Active**.
7. Click **Save**.

:::info
Banners are displayed as a horizontal carousel. Lower order numbers appear first.
:::

## FAQs

FAQs are organized into topics (categories). Each topic contains one or more question-and-answer pairs.

Navigate to the **FAQs** section in the admin sidebar.

![FAQs List](/images/panel/faqs-list.png)

### Managing FAQ Topics

1. Go to **FAQs** in the sidebar.
2. Click **Add Topic** to create a new category (e.g., "Booking", "Payments").
3. Enter the topic name and save.

### Managing FAQ Items

1. Open an existing topic.
2. Click **Add FAQ**.
3. Enter the **Question** and **Answer**.
4. Toggle status to **Active**.
5. Click **Save**.

:::info
Disabled FAQ items are hidden from the app and web frontend. Topics with no active FAQs are also hidden.
:::

## Blogs

The blog section lets you publish articles and news for your users.

Navigate to the **Blogs** section in the admin sidebar.

![Blogs List](/images/panel/blogs-list.png)

### Blog Categories

Before creating blog posts, set up at least one category.

1. Go to **Blogs → Categories**.
2. Click **Add Category**.
3. Enter the category name.
4. Click **Save**.

### Creating a Blog Post

1. Go to **Blogs** and click **Add Blog**.
2. Select a **Category**.
3. Enter the blog **Title**.
4. Upload a **Thumbnail / Cover Image**.
5. Write the content using the rich text editor.
6. Set the status to **Published** or **Draft**.
7. Click **Save**.

| Field | Description |
|---|---|
| Title | Blog post headline |
| Category | Assign to a blog category |
| Thumbnail | Cover image shown in listing |
| Content | Full blog body (supports rich text / HTML) |
| Status | Published (visible) or Draft (hidden) |

## How It Works

The How It Works section explains your platform's process to new users. It is displayed as a step-by-step guide in the app and on the web.

Navigate to the **How It Works** section in the admin sidebar.

![How It Works](/images/panel/how-it-works.png)

### Managing Steps

1. Go to **How It Works** in the sidebar.
2. Click **Add Step**.
3. Enter the **Title** and **Description** for the step.
4. Upload or select an **Icon**.
5. Set the **Display Order**.
6. Click **Save**.

| Field | Description |
|---|---|
| Icon | Visual icon representing the step |
| Title | Short step heading |
| Description | Brief explanation of the step |
| Display Order | Controls the sequence of steps shown |

:::info
Steps are displayed in ascending order. Keep descriptions concise — one or two sentences per step works best.
:::
