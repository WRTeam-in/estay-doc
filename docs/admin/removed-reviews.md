# Removed Reviews

A permanent archive of every review that's been taken down via an approved [removal request](./review-removal-requests.md) — for your records, not a working queue.

:::info Multi-mode only
This page exists only when the platform is running in [Multi Mode](./overview.md#single-mode-vs-multi-mode).
:::

---

## The List

Each entry shows the review (rating, comment, linked property and booking) and who approved its removal.
