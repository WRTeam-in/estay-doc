# Property Management

Manage all properties listed on your eStay platform — including their room types, amenities, and categories.

---

## Properties

**Navigate to:** Sidebar → **Properties**

![Property List](/images/panel/property-list.png)

### Adding a Property

Click **Add Property** to open the property creation form.

![Add Property](/images/panel/property-add.png)

| Field | Description |
|---|---|
| **Name** | Display name of the property. |
| **Description** | Full description shown on the property listing page. |
| **Address** | Street address of the property. |
| **Location (Map)** | Pin the property location on the map using coordinates or address search. |
| **Category** | Select the property category (e.g., Hotel, Villa, Apartment). |
| **Amenities** | Select amenities available at the property (e.g., WiFi, Pool, Parking). |
| **Images** | Upload multiple images for the property gallery. |
| **Check-in Time** | Default check-in time (e.g., `14:00`). |
| **Check-out Time** | Default check-out time (e.g., `11:00`). |
| **Policies** | Cancellation policy, pet policy, and other property-specific rules. |

:::info
At least one image is required before a property can be published and visible to guests.
:::

### Editing a Property

Click the **Edit** icon next to any property in the list to update its details.

### Deleting a Property

Click the **Delete** icon next to a property. Deletion is a soft delete — the property is hidden but its data is retained.

:::warning
Deleting a property will also hide all its associated room types from the platform. Existing bookings will not be affected.
:::

## Room Types

**Navigate to:** Sidebar → **Properties** → **Room Types**

Add and manage room types under each property. Each property can have multiple room types.

![Room Type List](/images/panel/room-type-list.png)

### Adding a Room Type

Click **Add Room Type** and fill in the following fields:

![Add Room Type](/images/panel/room-type-add.png)

| Field | Description |
|---|---|
| **Property** | The property this room type belongs to. |
| **Name** | Name of the room type (e.g., Deluxe Suite, Standard Room). |
| **Price Per Night** | Base nightly rate for this room type. |
| **Max Guests** | Maximum number of guests allowed. |
| **Beds** | Number and type of beds (e.g., 1 King, 2 Twin). |
| **Bathrooms** | Number of bathrooms in the room. |
| **Size** | Room size in square meters or square feet. |
| **Amenities** | Room-specific amenities (e.g., Air Conditioning, Balcony, Minibar). |
| **Images** | Upload images specific to this room type. |

### Editing or Deleting a Room Type

Use the **Edit** or **Delete** icons in the room type list. Deleting a room type is a soft delete.

## Amenities

**Navigate to:** Sidebar → **Properties** → **Amenities**

Manage the global list of amenities that can be assigned to properties and room types.

| Action | Description |
|---|---|
| **Add Amenity** | Create a new amenity with a name and icon. |
| **Edit Amenity** | Update the name or icon of an existing amenity. |
| **Delete Amenity** | Remove an amenity. It will be unassigned from all properties automatically. |

Common amenities: WiFi, Swimming Pool, Parking, Gym, Restaurant, Spa, Air Conditioning, Pet Friendly.

---

## Property Categories

**Navigate to:** Sidebar → **Properties** → **Categories**

Manage the categories used to classify properties (e.g., Hotel, Resort, Villa, Apartment, Hostel).

| Action | Description |
|---|---|
| **Add Category** | Create a new property category with a name and optional image. |
| **Edit Category** | Update an existing category's name or image. |
| **Delete Category** | Remove a category. Properties using this category will need to be reassigned. |
