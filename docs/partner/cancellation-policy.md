# Cancellation Policy

The partner's own refund rules, scoped to whichever country they're currently working in. This is what applies to a property whose [cancellation policy source](./adding-a-property.md) is set to **custom** rather than inheriting the admin default.

---

## Cutoff Time

The **Cancellation Cutoff Time** sets the time of day a cancellation must happen by to count as "that day" for the rules below.

---

## Rules

Each rule maps **days before check-in** to a refund outcome — refundable (with a percentage) or non-refundable. Add, edit, or delete rules; only one rule can exist per day count.

:::warning The 0-day rule can't be deleted
A mandatory fallback rule for "0 days before check-in" always exists — you can edit its refund percentage, but not remove it. This is what applies to a last-minute or day-of cancellation if nothing else matches.
:::
