# Partner Panel Overview

The **Partner Panel** is a separate control center for property owners, available only when the platform is running in [Multi Mode](/docs/admin/overview#single-mode-vs-multi-mode). It's a different login, a different URL, and a different sidebar from the admin panel — a partner only ever sees and manages their own properties, rooms, and bookings.

This page gives you the big picture. Each section links to a detailed guide.

:::tip New here?
A partner gets in by [creating a basic account](./registration.md) on the public website, then completing the [Setup Wizard](./setup-wizard.md) — country, property type, profile, address, and documents — right after their first login. Once an admin approves them, they [submit their first property](./property-management.md) for its own admin verification before it goes live.
:::

---

## Who Uses This Panel

The Partner Panel is for the **property owner** side of the marketplace — not platform staff. Compare it to the admin panel:

| | Admin Panel | Partner Panel |
|---|---|---|
| Used by | Platform staff | Property owners (partners) |
| Sees | Every partner, every property, every country | Only their own properties and bookings |
| Approves | Partners and their properties | Nothing — submits for admin approval |
| Payments | Configures commission, reviews payouts | Views wallet balance, requests withdrawals |

---

## Property Context

If a partner owns more than one property, a **property switcher** in the topbar scopes most of what they see — bookings, rooms, availability, and so on — to the currently selected property, the same way the admin panel's country/property switcher works.

## Navigation Map

The left sidebar groups everything into sections:

| Section | What it's for | Guide |
|---|---|---|
| **Bookings** | All bookings, today's check-ins/check-outs, availability calendar. | [Bookings](./bookings.md) |
| **Room Management** | Room types, individual rooms, and room-level inventory. | [Room Management](./room-management.md) |
| **Review Monitoring** | All guest reviews, plus requests to have a review removed. | [Reviews](./reviews.md) |
| **Wallet Management** | Wallet balance, earnings, and withdrawal requests. | [Wallet](./wallet.md) |
| **Property Management** | Add and manage properties. | [Property Management](./property-management.md) |
| **Cancellation Policy** | The partner's own cancellation policy, or inherit the platform default. | [Cancellation Policy](./cancellation-policy.md) |
| **Location Management** | Countries the partner operates properties in. | [Location Management](./location-management.md) |
| **Settings** | Notification preferences and account settings. | [Settings](./settings.md) |

Outside the sidebar groups, a partner can also reach **My Profile** from the user menu.

## Where to Go Next

- **Just registered?** → Complete the [Setup Wizard](./setup-wizard.md), then wait for [Partner Verification](/docs/admin/partner-verification) on the admin side.
- **Adding a property?** → [Property Management](./property-management.md) — a property must pass admin verification before it's bookable.
- **Running day-to-day?** → [Bookings](./bookings.md), [Room Management](./room-management.md).
- **Getting paid?** → [Wallet](./wallet.md) for balance and withdrawal requests; payout amounts are set by the admin's Commission configuration.
